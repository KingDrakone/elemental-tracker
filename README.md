# Elementais Tracker – Fortnite Elemental Collection Tracker

Elementais Tracker is a tool designed to help Fortnite players track, organize, and complete their Elemental collection automatically and efficiently.

The program works in the background while you play, monitoring your Fortnite screen to detect newly discovered Elementals.

### 1. Automatic Recognition

The program scans your game screen and detects when the message "NEW – ADDED TO COLLECTION" appears. Using image recognition technology, it compares the displayed Elemental with the reference images stored in the program.

When an Elemental is successfully identified, it is automatically added to your collection.

### 2. Organized Collection

All detected Elementals are displayed in a visual interface, organized by rarity:

- Rare
- Epic
- Legendary
- Mythic

You can also track each Elemental's variants:

- Normal
- Valuable
- Cursed

This makes it easy to see which Elementals you have already collected and which ones you still need.

### 3. In-Game Overlay

The program includes an Overlay system that allows you to track your collection without leaving Fortnite.

The overlay can display:

- Collection progress.
- Discovered Elementals.
- Recently unlocked Elementals.

You can customize its size, opacity, appearance, and position on your screen.

### 4. OBS Integration

Elementais Tracker includes an OBS Studio overlay, allowing you to display your collection progress directly on your livestream.

This lets your viewers follow your progress and see which Elementals you discover during your streams.

### 5. Synchronization and Profiles

Your collection is saved locally on your computer, allowing you to keep your progress between gaming sessions.

The program also supports multiple profiles and automatic detection of Fortnite account changes.

### 6. Manual Controls

If necessary, you can manually mark Elementals, change their variant status, and track your collection progress directly through the interface.

### 7. Customization

The program offers several customization options:

- Portuguese and English language support.
- Full or simplified overlay.
- Adjustable transparency.
- Adjustable overlay size.
- Custom overlay positioning.
- Keyboard shortcuts.

### Main Purpose

The goal of Elementais Tracker is to make collecting Fortnite Elementals easier, more organized, and more interactive.

It allows players to track their collection in real time while giving livestream viewers the opportunity to follow every discovery.

### Main Keyboard Shortcuts

| Shortcut         | Function            |
| ---------------- | ------------------- |
| Ctrl + Shift + O | Show/Hide Overlay   |
| Ctrl + Shift + L | Lock/Unlock Overlay |

One of its biggest advantages: You don't need to manually register every Elemental. Whenever the program successfully recognizes a new discovery notification in Fortnite, it automatically updates your collection.
